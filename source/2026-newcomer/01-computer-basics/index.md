# 01 计算机基础能力

## 一、模块定位

计算机基础能力是后续学习编程、人工智能、大语言模型与智能体开发的前置基础。本模块并不追求系统讲解计算机专业全部知识，而从新生第一次接触开发环境所遇到的实际问题出发，帮助培养基础的操作能力：能够管理文件，能够使用终端，能够理解基本网络概念，能够连接并操作服务器，能够独立配置开发环境。

完成本模块后，学习者应逐步摆脱对图形化界面和他人配置的依赖，具备基本的问题定位、环境管理和服务器操作能力，为后续的工作做好准备。

## 二、学习目标

完成本模块后，你应能够：

1. 理解操作系统、文件、目录、路径、进程和权限等基本概念。
2. 使用终端完成文件管理、程序运行和系统信息查看。
3. 理解 IP 地址、端口、域名、HTTP 和 SSH 等基本网络概念。
4. 使用 SSH 连接 Linux 服务器，并完成基本文件和进程操作。
5. 使用包管理器、虚拟环境和环境变量管理开发环境。
6. 遇到环境或运行错误时，能够通过报错信息、日志和搜索逐步定位问题。
